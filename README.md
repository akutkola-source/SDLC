## Описание проекта
Шаблон программного проекта (Project Template) для последующего проектирования, разработки, тестирования и контроля версий.

## Структура репозитория
* `/src` — исходный программный код разрабатываемой системы;
* `/include` — заголовочные файлы интерфейсов;
* `/docs` — техническая документация и отчеты;
* `/tests` — тесты программных модулей.
