# Лабораторная работа № 3 — «Разработка и документирование бизнес-требований»

Дисциплина «Жизненный цикл разработки программного обеспечения».
Выполнил: Шурхай Н.А., гр. 434701. Вариант № 1 — архивные курсы валют для расчёта налогообложения ИП.

## Проект «КурсНалог» (RateTax)

Desktop-приложение для Windows: получает официальные курсы Национального банка Республики Беларусь
(api.nbrb.by), ведёт книгу учёта доходов ИП с автоматическим пересчётом валютной выручки в BYN
по курсу на дату поступления и рассчитывает налог за квартал или год.

Стек: C++17, классический WinAPI (CreateWindowEx, оконная процедура, цикл сообщений, Common Controls),
графики — GDI, сеть — WinINet, данные — текстовые файлы в `%LOCALAPPDATA%\RateTax`.
Сторонние библиотеки и фреймворки не используются.

## Сборка и запуск

1. Открыть `src/RateTax.sln` в Visual Studio Community 2022/2026
   (нужна нагрузка «Разработка классических приложений на C++»).
2. Выбрать конфигурацию **Release** / **x64**.
3. Нажать **Ctrl+F5** (запуск без отладки).

Из командной строки разработчика: `msbuild src\RateTax.sln /p:Configuration=Release /p:Platform=x64`,
результат — `src\x64\Release\RateTax.exe`.

## Возможности

- **Курс на дату** — официальный курс USD, EUR, RUB, CNY, PLN; график динамики за период; конвертер.
- **Книга доходов** — добавление, изменение (двойной щелчок), удаление поступлений; курс подставляется
  автоматически с учётом масштаба (например, RUB — за 100); фильтр по кварталу/году; экспорт в CSV для Excel.
- **Расчёт налога** — налоговая база и сумма налога по заданной ставке; экспорт в CSV; печать
  (PDF — через принтер «Microsoft Print to PDF»).
- **Настройки** — ставка по умолчанию, резервная копия и восстановление; автоматическая копия раз в 7 дней.
- Полученные курсы кэшируются и доступны без Интернета.
